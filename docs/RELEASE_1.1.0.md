# Android 1.1.0 升级说明

日期：2026-10-18。沿用现有项目与五个底部入口，包名 `com.jinriyouxu.app`，Android versionCode 为 6。

## 本轮变化

- 将“复盘”入口升级为“笔记”，统一知识记录和复盘；提供搜索、筛选、置顶、手动复习、项目关联和来源链接。
- 新增富文本阅读与编辑、Markdown 粘贴、本机图片附件和大图查看。停止输入约 400ms 保存，返回、完成或进入后台立即提交；保存失败保留草稿并允许重试。
- 项目保留原有展开操作，增加任务／相关笔记详情；笔记可转为待办，任务保留来源笔记入口。
- 保留暖米白、砖红、鼠尾草绿及纸张卡片；悬浮导航和工具栏采用轻毛玻璃。页面改为短淡入淡出，没有左右位移；保留流体导航和已确认的筛选过渡，移除动效设置项。
- 接入 Android 系统通知，提供权限、提醒策略、提前时间及测试通知；完成、删除或改期时同步更新系统通知队列。
- 桌面启动图标使用用户提供的旧版叶片原图。

## 数据与升级

IndexedDB 升级至 schema 3，迁移前保存快照，旧复盘幂等迁入笔记并保留日期、心境、统计和图片信息。显式空库不会重新填充示例。

本机 JPEG、PNG、WebP 按 SHA-256 独立保存并去重，保留原图；完整备份改为包含图片的 ZIP，兼容旧 v1/v2 JSON。恢复前校验数据、引用和附件哈希，校验失败不覆盖现有数据。外链图片仍需要联网。

本项目沿用原签名。用户提供的 2.3.0 APK 包名是 `cn.orderlife.mobile`，仅作为图标与旧同步流程参考；它与本项目不能相互覆盖安装或直接读取数据。

## 同步与保留范围

已定义任务、项目、笔记及图片的同步仓储和传输接口，保留修订与删除标记；参考旧 APK 的配对、字段时钟和附件流程。真实网络、配对和自动传输尚未接入，需要办公室电脑最新版源码核对字段映射与冲突策略。界面明确显示尚未接入，设备偏好不随业务数据同步。详见 [同步接入文档](SYNC.md)。

整体导航重组与功能精简仅记录为 [讨论建议](SIMPLIFICATION.md)，本轮不据此删改功能，也不修改本机旧桌面源码。

## 验证与交付

类型检查、生产构建、Asia/Shanghai 和 UTC 各 47 项测试通过；Android Release、lintVital、同签名与 APK Web 资源一致性检查通过。浏览器检查笔记、附件、项目关联、转待办、导航隐藏和缩小视口编辑。详见 [验证记录](VALIDATION.md)。

未连接真实 Android 设备，系统通知横幅、锁屏、重启、省电限制及中文输入法仍需安装后验收；浏览器视口模拟不视为真机测试。未进行真实手机与电脑传输测试。

仓库保存源码、资源、构建配置和文档。签名私钥、密码、本机环境配置、用户数据与安装包不纳入版本控制；APK 已单独交付。构建步骤见 [ANDROID.md](../ANDROID.md)。
