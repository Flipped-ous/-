本轮在现有 Android 工程上升级，包名 com.jinriyouxu.app、versionCode 7，沿用原签名与旧版叶片图标。覆盖安装保留本应用的数据；请勿先卸载。图标来源的独立 cn.orderlife.mobile 应用与本包不同，不能相互覆盖。

## 使用变化

- 待办页默认月历，可收起为所选日期所在周；翻月／翻周、回到今天、未完成圆点及所选日期任务。搜索覆盖全部日期，清空后恢复原视图。逾期和未安排独立查看。
- 去掉四象限界面，保留全部四种重要程度。今天页可组合完成状态与重要程度筛选；概览仍显示今日整体进度。
- 新建／编辑采用紧凑底部面板，日期使用内嵌月历，小时／分钟数字输入；编辑已有任务先展示内容，不自动弹键盘。保留项目、笔记来源与原排期。
- 收工整理集中查看之前逾期和今天未完成任务。默认不选择；选择后可移到明天、选择日期或暂不安排，确认才保存。处理部分任务后继续显示剩余项，全清后才显示完成页。
- 最近一批排期操作可撤销；后续编辑过或删除的任务跳过，不覆盖新编辑、不复活已删除任务。关闭面板清除本次撤销记录，不修改任务。
- 改期保留具体时间，旧单独提醒按相对原排期的偏移迁移，已过期提醒不补发。暂不安排清除日期、时间和单独提醒。旧数据仅在 dueAt 中存具体时间时也能保留。

## 每日收工提醒

更多 → 提醒策略 → 每日收工。默认启用、每天 21:00，可修改或关闭；与单项任务提醒策略独立，但共用系统通知权限。需允许通知，准确时间权限不足时可能延迟。

原生闹钟接收器读取本机已保存的任务排期镜像，在触发时计算逾期及当天未完成数量；没有任务不通知。21:00 时当天 21:30 的任务会计入，但不标为逾期，也不自动选中改期。点击通知进入收工整理；忽略通知不改动任务。

每个本地日期最多通知一次。重启、更新应用、修改时区和系统时间后重新计算下一次检查；错过当天设定时间不补发。强行停止应用、厂商后台限制或系统撤销通知授权会影响实际投递。

## 保存与兼容

保持 schema 3，通过可选设置字段兼容旧数据。批量变更先在同一快照事务落盘，再更新列表与提醒；失败保留选择，可重试。任务照常产生修订记录。完整备份可携带本机提醒设置，但业务同步不交换设备偏好。

原生镜像不含笔记、图片和标题，只保存任务时间戳、待完成状态、提醒时间与开关。镜像失败单独提示并可重试，不把已成功的批量保存误报为失败。真实电脑同步仍未接入。
