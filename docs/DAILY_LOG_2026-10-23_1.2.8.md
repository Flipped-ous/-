# 2026-10-23 补充日志：1.2.8

根据手机反馈继续调整项目拖动、笔记搜索与工具行对齐，交付版本1.2.8 / versionCode15。

项目拖动原先450ms启动、只有源卡移动、松手等保存后列表跳变。现在触摸启动240ms、鼠标纵向拖动直接启动，MotionValue跟手，预先缓存卡片几何尺寸，按越过相邻中心点计算让位，其他卡片160ms移动；本地只更新跨槽预览，不逐帧保存。松手归位、事务落盘，完成后释放冻结列表，减少闪回；取消复位不提交，保留左滑删除。新建项目使用44px圆形＋。

笔记搜索由原生键盘可见性独立订阅处理，即使其他弹窗持有导航隐藏也能收到收起事件。Enter、Escape和失焦折叠输入框，删除搜索叉号；关键词和结果保留，收起时显示搜索摘要，再点图标编辑。点击结果先处理动作，避免失焦收起造成列表上移而错点。

三个日历工具入口共用CompactEntry，统一32px显示、44px点击区、角标、圆角与行高。实际DOM测量三者卡片top、bottom和中心一致。

新增两项拖动几何测试与一项键盘事件测试，当前80项前端测试、9项JVM测试及Release/lintVital通过。独立浏览器库使用真实鼠标从第一项拖到第二项，顺序换位；重载后仍保持，所有卡片位移均none，未误开项目。搜索Enter折叠、关键词保留、无叉号、搜索中进入笔记与返回通过，控制台无error。320px和390px布局检查另见验证记录。

未连接Android真机，真实键盘收起、240ms触摸启动和连续拖动仍需安装验收。浏览器测试数据不进入APK，签名与图标按原版本校验；本轮按用户要求提交GitHub原开发分支，并更新原PR。
