# 今日有序 1.2.2

本次仅优化提醒设置的布局，保留提醒规则与任务、笔记、项目数据。

- 每日收工合并为标题、时间、开关一行；点击时间才展开数字输入，确定后应用，取消不修改。关闭收工时保留原时间、禁用编辑。
- 任务提醒方式以四段紧凑选项展示；提前提醒采用三列两行，砖红选中态。
- 权限、长说明、队列数量与测试通知收进“权限与提醒说明”。未授权时仍在顶部提供开启入口，不把浏览器显示为手机已授权。
- 测试通知只用于检查系统能否接收，约 5 秒后投递，不创建或修改待办。
- 标题和关闭按钮固定，正文独立滚动，小屏仍能关闭面板。时间输入不显示无意义的清除入口，任务编辑的清除时间功能保持。

版本 1.2.2 / versionCode 9，沿用 com.jinriyouxu.app、原签名和图标。检查详见 VALIDATION.md；未进行 Android 真机通知和键盘测试。本轮未上传 GitHub。
