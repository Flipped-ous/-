# 今日有序

沿用 Stitch 视觉设计的 Android 待办与笔记应用，当前版本 **1.1.0**。包含今天、待办、项目、笔记、更多五个页面，保留暖米白背景、砖红主色、鼠尾草绿和圆角纸张卡片。

应用使用 React、TypeScript、Vite 和 Capacitor，支持浏览器预览和 Android 离线运行。Android 包名为 `com.jinriyouxu.app`。

## 开发与检查

使用 Node.js 24、pnpm 11.25.0：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

开发预览默认运行在 `http://localhost:3000`。

```sh
pnpm run lint   # TypeScript 检查
pnpm test       # 回归测试
pnpm run build # 生产构建，输出 dist/
pnpm check     # 顺序执行以上检查
```

Android 环境、构建和签名步骤见 [ANDROID.md](ANDROID.md)，版本调整见 [CHANGELOG.md](CHANGELOG.md)，本轮交付摘要见 [1.1.0 升级说明](docs/RELEASE_1.1.0.md)。

## 当前功能

- 统一的任务增删改、完成、筛选、搜索、排序和项目归属；删除后约 5 秒内可撤销。
- 日期按本地日历显示；修改任务标题保留原截止日期，支持 `00:00`。具体时刻使用紧凑的小时、分钟输入框。
- 左滑删除、右滑完成；松手位移达到卡片宽度 45% 才提交，拖回或取消不提交。长按 450ms 可开始排序。
- 项目列表保留展开操作，新增独立详情的任务／相关笔记切换。
- 笔记统一知识和复盘，支持搜索、类型筛选、待复习、置顶、项目关联、来源、字号和转待办；任务保留来源笔记入口。
- Tiptap 全屏富文本编辑与 Markdown 粘贴，支持标题、列表、引用、代码和表格；停止输入约 400ms 保存，完成／返回／后台立即提交，保存失败保留输入并可重试。
- 本机 JPEG/PNG/WebP 图片按 SHA-256 独立保存、不压缩原图、单图最大 50 MB，支持离线和大图查看；外链图片明确标记联网查看。
- IndexedDB schema 3 保存，旧复盘幂等迁入笔记，日期、心境、统计和图片信息保留；笔记与图片独立写，不随主快照和每次输入重写。
- 含图片的 ZIP 备份，兼容 v1/v2 JSON 导入；先完整校验附件、保护原快照，再原子覆盖／合并，失败不替换数据。
- 浅色、深色主题；移除动效等级和开关，使用标准默认交互并尊重系统减少动态效果。
- Android 真实系统提醒：通知权限、准确时间设置、温和／仅重要／有声／关闭、提前提醒和测试通知；完成／删除／改期时更新系统队列。

## 交互表现

今天、待办的页面进入、任务卡片、数字、详情展开和保存反馈保持即时响应。卡片拖动直接跟手，标题、说明和时间随卡片一起移动。

筛选胶囊平滑滑动；今天页筛选保留已确认的约 200ms 整体列表过渡。普通勾选、编辑和滚动不触发列表过渡。系统要求减少动态效果时直接切换。页面切换约 160ms 淡入淡出，不左右移动；今天与待办常规内容保持即时响应。

底部导航只显示图标，选中背景具有流体滑动效果。文本输入、阅读、编辑和弹窗期间隐藏导航，结束后恢复。Android 系统栏与应用主题一致；轻毛玻璃仅用于悬浮导航、阅读顶栏及编辑工具栏。

Android 包名仍为 `com.jinriyouxu.app`，沿用本项目签名；叶片图标取自用户给出的 `cn.orderlife.mobile` 2.3.0，两个应用包名不同，不能覆盖安装或直接互读数据。

## 提醒规则

仅待完成且设置了日期与明确 dueTime 的任务安排通知；仅日期不触发午夜，显式 00:00 有效。提前 0/5/10/15/30/60 分钟可选，非零时保留到期提醒。点击任务通知打开任务。未授权通知时不安排，准确时间未授权可能延后。温和渠道无声并允许振动，有声渠道使用系统提示音；系统渠道设置优先。重启恢复由插件接收器负责，强制停止、勿扰与厂商省电可能影响投递。浏览器不发送系统通知。

精简建议见 [docs/SIMPLIFICATION.md](docs/SIMPLIFICATION.md)，仅供讨论，不据此删改功能。
