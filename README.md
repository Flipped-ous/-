# 今日有序

沿用 Stitch 视觉设计的 Android 待办与复盘应用，当前版本 **1.0.4**。包含今天、待办、项目、复盘、更多五个页面，保留暖米白背景、砖红主色、鼠尾草绿和圆角纸张卡片。

应用使用 React、TypeScript、Vite 和 Capacitor，支持浏览器预览和 Android 离线运行。Android 包名为 `com.jinriyouxu.app`。

## 开发与检查

使用 Node.js 24、pnpm 11.25.0：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

开发预览默认运行在 `http://localhost:3000`。

```sh
pnpm run lint   # TypeScript 检查
pnpm test       # 回归测试
pnpm run build # 生产构建，输出 dist/
pnpm check     # 顺序执行以上检查
```

Android 环境、构建和签名步骤见 [ANDROID.md](ANDROID.md)，版本调整见 [CHANGELOG.md](CHANGELOG.md)。

## 当前功能

- 统一的任务增删改、完成、筛选、搜索、排序和项目归属；删除后约 5 秒内可撤销。
- 日期按本地日历显示；修改任务标题保留原截止日期，支持 `00:00`。具体时刻使用紧凑的小时、分钟输入框。
- 左滑删除、右滑完成；松手位移达到卡片宽度 45% 才提交，拖回或取消不提交。长按 450ms 可开始排序。
- 项目管理、复盘记录和基于任务时间字段的统计。
- IndexedDB schema 2 保存任务、项目、复盘及设置；先恢复后保存，事务失败时尝试 localStorage 快照并显示错误。
- JSON 备份导入校验，支持覆盖或按 `updatedAt` 合并；Android 导出通过系统文件分享面板操作。
- 浅色、深色主题及动效等级设置，尊重系统减少动态效果设置。

## 交互表现

今天、待办的页面进入、任务卡片、数字、详情展开和保存反馈保持即时响应。卡片拖动直接跟手，标题、说明和时间随卡片一起移动。

筛选胶囊平滑滑动；今天页切换全部、待完成、已完成时，整块列表进行约 200ms 的淡入淡出和最多 8px 的横移。普通勾选、编辑和滚动不触发列表过渡。全局关闭动效或系统要求减少动态效果时直接切换。

底部导航只显示图标，选中背景具有流体滑动效果。文本输入和弹窗期间隐藏导航，结束后恢复。Android 系统栏背景与应用主题保持一致。

## 范围与数据

设备配对、局域网同步和提醒策略目前为演示流程，尚未接入真实同步协议或系统通知。复盘统计只使用已保存的任务时间字段，不虚构专注时长。

浏览器和手机各自保存本地数据，可通过 JSON 备份迁移。旧数据会迁移到统一模型；显式空数据不会被演示数据覆盖，不支持的未来 schema 会报错。旧数据缺失的历史时间无法还原。
